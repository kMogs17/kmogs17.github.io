I am currently a senior software engineer on a newly formed modernization team operating with startup-like autonomy to redesign and externalize legacy healthcare processing systems.

On this project, I am designing and implementing microservices for healthcare systems, including capitated services, using Java, Spring Boot/Batch, Kafka, and Databricks for real-time data streaming and analytics.

Collaborated with a globally distributed medium team (~30 people) to manage developers, enforce coding standards, and support Agile and Scrum practices;
While building this application, I had several notable achievements.
I engineered a capitation engine capable of processing 1.2 million members in 42 minutes, significantly reducing total runtime.
I built a high-performance file generation utility capable of processing 372,000 members in 22 seconds.
I migrated services from on-prem to cloud and hybrid-cloud, resulting in $3 million in savings.
I led externalization of legacy monolith components, extracting them into independently deployable services.
I led modernization initiatives, converting legacy monolith components into new microservices to enhance performance, scalability, and maintainability.
I identified and resolved performance bottlenecks, improving API and job throughput by 95%+ via caching, multithreading, and process simplification.
I innovated AI-driven solutions, leveraging ChatGPT and other ML tools to improve development quality, automation, and insights.
I integrated services into CI/CD pipelines (GitHub Actions, Jenkins) and deploy across Kubernetes, Azure, and Google Cloud Platform (GCP) environments.
I led database optimization and migration projects: MySQL → PostgreSQL and Cassandra → MongoDB.
I reduced story splits by 40% through accurate sprint planning.
