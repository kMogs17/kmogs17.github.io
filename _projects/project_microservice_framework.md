I am currently a senior software engineer on a newly formed modernization team operating with startup-like autonomy to redesign and externalize legacy healthcare processing systems.

I joined this project when it was formed in June 2020. On this project, I am designing and implementing microservices for healthcare systems, including capitated services, using Java, Spring Boot/Batch, Kafka, and Databricks for real-time data streaming and analytics.

I am collaborating with a globally distributed medium team (~30 people) to manage developers, enforce coding standards, and support Agile and Scrum practices.

While building this application, I had several notable achievements.

- Engineered a capitation engine capable of processing **1.2 million members in 42 minutes**, significantly reducing total runtime.
- Built a high-performance file generation utility capable of processing **372,000 members in 22 seconds**.
- Migrated services from on-prem to cloud and hybrid-cloud, resulting in **$3 million in savings**.
- Led **externalization** of legacy monolith components, extracting them into independently deployable services.
- Led **modernization** initiatives, converting legacy monolith components into new microservices to enhance performance, scalability, and maintainability.
- Identified and resolved performance bottlenecks, improving API and job throughput by **95%+ via caching**, **multithreading**, and **process simplification**.
- Innovated **AI-driven solutions**, leveraging **ChatGPT** and other ML tools to improve development quality, automation, and insights.
- Integrated services into CI/CD pipelines (**GitHub Actions**, **Jenkins**) and deploy across **Kubernetes**, **Azure**, and **Google Cloud Platform (GCP)** environments.
- Led database optimization and migration projects: **MySQL → PostgreSQL** and **Cassandra → MongoDB**.
- **Reduced story splits by 40%** through accurate sprint planning.
- Implemented a **Retrieval-Augmented Generation (RAG) pipeline** using **Python**, **LangGraph**, **ChromaDB**, **Azure Databricks**, and **GPT-4 models** to support question-answering over medical documentation.
- Engineered **validation pipelines**, **embedding strategies**, and **human-in-the-loop** review mechanisms to ensure correctness, compliance, and safe deployment of AI-assisted outputs in regulated environments.
